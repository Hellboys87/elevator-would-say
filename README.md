# What the Elevator Would Say

My entry for the "What the Elevator Would Say" bounty: the funniest one line a talking elevator could say, in the elevator's own voice. The joke plays on the elevator's entire existence — it spends all day travelling up and down through a building, yet unlike every passenger it carries, it never gets to enjoy the view from a window seat.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/elevator-test-out node main.ts
```
